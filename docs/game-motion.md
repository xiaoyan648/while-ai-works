# 小游戏视觉与动效

2026-09-28。在 `feat/menubar-redesign` 的最新主界面基础上，游戏沿用雾绿强调色、系统字体、轻阴影与短促反馈。

## 本轮实现

- **擦污渍**：雾绿布料、轻织纹、柔和折痕、受力翻角；接触点立即跟随鼠标，仅边缘带少量惯性。污渍包含指印、水痕、轻尘。擦净时出现一次短高光。
- **捏气泡**：象牙白指示手，指腹位置固定、指节局部运动；按下期间锁定方向，松手后平滑转向，边缘带迟滞区。薄膜从局部凹陷连续变成两道软褶。快速松手保留短暂按压，扫泡按轨迹进入顺序调度。
- **敲木鱼**：温润木色、稀疏木纹、雾绿底垫；约 35ms 下落，接触帧触发计数、声音和触觉，再用约 220ms 收稳。连续点击从当前槌姿态开始，相近的数字提示合并，真实计数独立保留。
- **钓鱼**：提示、对抗条、进度、鱼获卡使用同一套明暗自适应 HUD。浮漂咬钩改成一次下沉，鱼线终点与浮漂一致。普通鱼获更安静，首次发现、纪录和解锁才提高强调程度。

本轮使用 AppKit/Core Graphics 矢量形变与原生输入接入，没有新增游戏 Rive 资源。主界面和桌面猫咪继续使用现有 Rive 资源。气泡批量绘制和擦除判定仍由原生代码拥有。

## 实现约束

1. `ClothContact.sweep` 生成圆角接触区沿线移动后的完整轮廓，位图擦除和 `StainProgress.erase(where:)` 使用同一个 CGPath。快速拖动不依赖离散刷头数量，也不再使用相互不一致的 29pt / 22pt 半径。
2. `BubbleContact.hit` 以线段进入圆的参数排序；鼠标抬起不会按数组顺序强制破裂。形变在 `poppedAt` 前后保持连续，动画状态不会重复计数。
3. `HandOrientation` 在按下时锁定当前显示姿态；转向只发生在悬停，并通过迟滞区避免边缘反复切换。
4. `PlayView` 使用 macOS 14+ 的 NSView Display Link，在实际显示器刷新时处理画面更新；离开窗口会失效和取消输入。静止道具不会持续请求重画。绘制限于脏区域。
5. 静止气泡缓存为 Retina 透明图像，按压、出现、塌陷、悬停气泡才实时矢量绘制。缓存最多 256 张，画布重建时清空。这样同时避免了真实 AppKit 窗口局部重绘时的渐变/透明边缘积累，并降低了绘制成本。
6. 减少动态效果保留静态受力、破裂结果与计数，去掉回弹、布角惯性、槌摆动和奖励漂浮。原有存档、钓鱼概率、鱼竿解锁规则保持原逻辑。

## 验证

```bash
bash scripts/check.sh
bash scripts/check-motion.sh
bash scripts/build.sh
codesign --verify --deep --strict 'dist/While AI Works.app'
```

`NativeMotionChecks` 为 76 项检查，覆盖双向扫泡、快速点击、偏心接触、取消、手势锁向、迟滞区、连续形变、擦除覆盖、反向高速擦动、木鱼事件/姿态时序、减少动态效果，以及连续 20 次局部重画后的静态像素一致性。使用隔离 UserDefaults，不写用户真实计数。

原有完整检查包括 46 项核心检查、原生交互/声音/工具热点检查、318 项钓鱼检查及 22/22 鱼种模拟、水族箱与主界面资源检查。

实际窗口验收使用生产绘制和输入代码编译的独立测试应用，完成拖动擦除、双向扫泡、木鱼点击、钓鱼抛竿和深浅背景切换。未做长时间桌面 FPS、GPU/功耗或人工听感测量，离屏导出不作为这些指标的证明。
