# 贴边猫条与桌面小猫

主界面右上角可直接选择「猫条｜宠物」，点击模式会立即显示对应形态，左侧猫图标单独控制显示/收起。选择与「设置 → 你的猫」及小猫右键菜单同步，并保存到偏好中。

- **贴边猫条**：默认竖向、右侧、贴边融合。拖动猫头靠近上/下沿会转为横向，靠近左/右沿会转为竖向；继续推到边缘会贴边融合。角落设有转向迟滞，避免来回抖动。松手后按显示屏和边缘比例保存位置。
- **桌面小猫**：保留自由拖动、摸摸、数字气泡和陪玩，独立记住位置。钓获庆祝结束后恢复当前形态。

只展示关注的客户端。悬停预览，点击固定卡片，再次点击或点外部收起；点猫头打开全部工作台。卡片上的 Rive 小猫趴在左上角，猫爪搭过边缘，尾巴从左侧绕到卡片后方，独立播放和暂停。支持系统、浅色和深色外观。

首次悬停停留 100 毫秒展开；卡片已展开时，滑过其他 Agent 立即切换，复用同一卡片及 Rive 画布，不重复淡入。离开后保留 450 毫秒供鼠标进入卡片或回复预览；较晚到达的旧图标离开事件不会取消新选择。点击固定或主动输入时停止悬停切换。

猫条只显示客户端标志、账户额度环和图标内部的运行动态；名字及会话数放在悬停提示与卡片中。四客户端窗口为 72 × 296 点。Claude 的额度环固定使用当前会话窗口，Codex 使用每周窗口；悬停显示具体窗口名，缺少对应窗口就留空，不用其他窗口代替。旧读数用灰色。额度环不随运行呼吸改变，避免把运行状态误读成额度。

工作中的 Agent 标志缓慢缩放（96%–104%，一个往返周期 3.6 秒），不添加外侧呼吸轮廓、光晕或阴影。Core Animation 只作用于标志，不写入应用状态，不重建会话列表；运行结束、窗口不可见或系统「减少动态效果」开启时保持静态图标。

末端三点菜单使用独立绘制的 3 点圆点和明确的浅/深色对比，不受原生菜单未激活时的图标染色影响。悬停显示轻微圆形底色及「猫条选项与设置」提示，保留原来的点击区域。

「边缘形态」可在猫条菜单或设置中切换：悬浮保留间距，贴边融合消除接触边间距，并采用内凹连接圆角。原生猫耳和细尾尖组成外轮廓；透明轮廓外的鼠标事件穿透。顶部融合使用 macOS 的可用显示区域边界，保留菜单栏及相机区域，不接管系统刘海。

详情卡片默认窗口为 380 × 400 点，标题区提供「会话 / 额度」页签，每次展开或切换 Agent 默认展示会话。待回答和待审批按请求时间优先排列，其次是最近 24 小时的明确完成事件、运行中的会话和较早历史，同级按事件时间倒序。只有来源明确报告的完成才能显示完成标识，停顿或没有工作不视为完成。

请求按原会话身份合并到对应 item，尚未索引的会话仍保留请求入口，不另造第二个会话。会话的默认对话按钮移除；待回答展示真实选项和主动输入入口，工具审批先展示操作内容，再提供拒绝与允许。完整内容可在 item 内审阅或主动打开处理浮窗；选择和发送按钮保留在滚动区外。发送中、待确认和失联时保留状态并禁用重复发送。原客户端撤回请求后自动移除对应控件。

正在填写或已选答案的请求暂时保持在前面，新的事件不会挤走输入框、切换回答目标或夺取焦点。自由输入紧接在问题下方；收起输入后以只读草稿预览保留内容，重新打开卡片不会自动获取键盘。

页签使用会话气泡与柱状图 SF Symbols，保留悬停说明、辅助功能名称和选中状态；有待处理请求时，会话图标右上角显示小角标。额度页签优先展示猫条所用的主要额度窗口，其他限制紧凑排列，时钟标记说明重置时间；套餐信息随账户额度标题展示。

消耗区固定在卡片底部，独立于上方额度列表的滚动与渐隐；显示本机最近会话的输入、输出和缓存读取，按三列对齐的 k/M/B 数字展示，悬停读取完整数值；细条用相同比例展示三类 Token 构成。缓存命中率为缓存读取 ÷（输入 + 缓存读取），与原引擎的输入归一化口径一致；没有缓存读取记录时显示未知，不估算命中率。会话按来源及 ID 去重，以最新快照累计，避免重复计算。总计包含三类 Token，统计范围明确为本机最近会话，不宣称是账户账单或 24 小时数据。无用量记录时展示等待记录说明。会话只显示两行回复摘要；文字由 Core Text 按实际宽度排版，截断时把省略号绘制在第二行文字末尾，仅在这个省略号上悬停显示完整回复；能完整显示的短回复不添加省略号或预览入口，长回复可在轻量预览中滚动。移开鼠标、收起详情卡、关闭回复预览或取消关注即清空并关闭预览。没有独立阅读窗口或额外的阅读图标。

状态预览不抢键盘焦点；主动打开对话或阅读浮窗后才接受键盘，关闭时释放焦点。卡片向屏幕内侧展开，在较小显示区域内缩小。

## Codex / Claude 数据

复用固定版本 Agent HUD 的原始 Core / Support，只启动 Codex 与 Claude provider。Claude 订阅额度通过本机官方引擎的 `get_usage` 查询；引擎需要完成 Claude 订阅登录。切换到官方 API 供应商不等于已登录订阅。原有工作状态监听与游戏逻辑继续运行。没有账户额度的登录方式显示不可用，不生成估算额度。

- 账户窗口显示**剩余百分比**、来源窗口名和重置时间；过期或失败的读数标为上次读数。时间到期本身不会把额度设为 100%。
- 会话显示输入、输出和缓存 tokens；这些数字是会话累计量，不混为账户费用或单次回答成本。
- 回复预览是客户端记录里的可见回答，可在设置关闭。卡片正文在内存中，不写入偏好或本应用的历史文件，不上传。
- Codex 桌面会话支持在卡片内补充消息：重新找到原 owner，读取当前状态，运行中使用 steer，明确 idle 时使用 start；保留原会话的模型和权限设置。只有匹配 owner、方法和 turn 的回执才显示送达。结果不确定时保留草稿、禁止自动重发。
- Claude 桌面会话可准确返回原客户端；CLI 会话可复制带原 UUID 的恢复命令。当前没有统一接口给任意正在运行的 Claude 会话直接输入，界面明确显示“在原客户端继续对话”。不会另起一个进程冒充原运行中的会话。

取消关注会停止对应的 provider。没有活动仅表示当前未检测到工作；只有客户端的完成事件显示“已回复”。

## 授权与提问

猫条的琥珀色角标表示待处理请求：单个问题显示 `?`，工具授权显示 `!`，多条请求显示数量。与账户额度环及工作状态点分别表达。点击对应客户端后，详情卡优先展示请求队列；选择选项后明确提交，也可输入自己的回答。单选、多选及各问题的草稿在内存中保存，收起卡片不会丢失草稿。

右上角展开图标打开独立、可调整大小的处理浮窗。长命令与工具输入在这里完整展示，授权按钮只在完整内容可审阅的位置提供；原客户端入口始终保留。计划审批仍返回 Claude 原客户端。打开卡片不抢焦点，主动输入或打开处理浮窗才接收键盘。

详情卡的「稍后／输入回答／提交」与授权操作区固定在底部，独立于内容滚动及底部渐隐；问题和选项较长时仍可发现并操作。多个客户端同时有请求时，全部工作台合并为一条队列，卡片保留客户端标志和项目名称。

- Codex 桌面异步问题卡与应用授权沿用上游 `CodexDesktopPermissions` 原 owner 桥接。回答前重新核对问题、owner 和 turn；收到匹配回执显示已发送，确认原请求撤下才消除角标。在原客户端回答也会同步撤下。读取失败不视为已处理；发送结果不确定时保留草稿并禁止重复发送。
- Codex 普通工具授权与 Claude Code 的工具授权、提问，通过「设置 → 跟随 AI → 安装交互监听」接入。安装后重启对应会话，并按客户端要求启用 hooks。仅添加本应用命名的 `PermissionRequest` handler，不替换其他 HUD、已有状态监听、供应商环境或权限模式。
- Codex Hook 只接收同一 `turn_id` 的本地记录明确声明 `approvals_reviewer: user` 的请求；自动审核或未知方式返回空输出。不会改变 Codex 的审核方式。
- Hook 回答成功显示「已交给原客户端」，不把本地传输完成声称为工具已执行。Claude 在原客户端回答后，helper 监听追加的匹配调用结果并退出，卡片随连接撤回。
- 关闭交互开关、关闭小猫、取消关注、退出或十分钟超时，会释放等待中的 Hook，返回客户端自身的审批流程，不默认允许。关闭卡片／「稍后」只收起界面，保留待处理提醒与草稿。

请求、草稿和决策只在本机内存及权限为当前用户的 Unix socket 中传递，不持久化、不上传。macOS 钥匙串或系统权限仍由用户在系统窗口确认。

用真实本机数据、隔离偏好打开评审版：

```sh
env -u ANTHROPIC_AUTH_TOKEN -u ANTHROPIC_API_KEY -u ANTHROPIC_BASE_URL -u CLAUDE_CODE_OAUTH_TOKEN \
  WHILE_AI_WORKS_CAT_PREVIEW=1 "dist/While AI Works.app/Contents/MacOS/WhileAIWorks"
```

评审模式不改写已安装应用的偏好，不自动开启游戏或音效。它会读取两种已关注客户端的数据。该模式打开回复预览，常规首次启动默认隐藏回复。
