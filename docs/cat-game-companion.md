# 小猫与小游戏联动

2026-09-28 实现记录。

## 表现

- 擦污渍：小猫前爪压着薄荷绿布，布料保留按压、折角与拖动惯性；墨猫和雪猫分别使用对应毛色。新增混合生成的猫爪印污渍，按实际墨迹采样擦除，爪印之间的留白不需要擦，擦净后只计数一次。
- 捏气泡：肉垫猫爪替代手指，接触中心即时跟随输入，保留连续轨迹命中、按压形变、方向过渡与回弹。
- 敲木鱼：猫爪握住槌柄，随槌一起敲下、接触和回弹；桌面猫进入安静专注表情。
- 钓鱼：等待时看向水面，咬钩和搏鱼时进入用力表情。成功后小猫双爪举起固定卡通小鱼庆祝，真实鱼种仍由鱼获卡片显示；钓到杂物则露出好奇表情。空罐头使用小金属罐造型。
- 鱼获庆祝统一展示 3.8 秒，与鱼获卡片一致；重新抛竿、切换游戏或关闭游戏会结束展示。小猫临时出现在钓鱼目标屏幕的钓鱼区域上方，结束后回到常驻位置；关闭常驻时则自动收起，不改变用户的常驻开关和保存位置。展示期间不拦截鼠标。
- Rive 新增 Proud Catch、Curious Catch、Fishing Effort、Quiet Focus，并重新生成随包资源。高频命中、擦除和工具跟手仍由原生绘图控制。

## 擦拭声音回归修复

布的接触面扩大后，旧声音检测仍只采样鼠标附近的九个点。连续小幅移动时这些点落在前一帧已擦净的区域，即使布的前缘正在擦除新污渍，也会被判断为没有摩擦声。现改为在擦除前检测同一条实际接触路径内的墨迹，并限制长距离移动的采样开销。

新增连续 2pt 拖动、已擦净区域、垂直镜像误采样的回归检查；NativeMotionChecks 95 项通过，NativeAudioChecks 音频解码、非静音和波形检查通过。未以这些检查代替实际扬声器听感验收。上述离屏预览视频本身没有音轨。
