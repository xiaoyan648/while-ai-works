# 0.20.2 发版验证

版本 0.20.2，构建号 40。修复 DSH 原会话入口、`dsh-tui` 监听配置和原生专属确认提醒。

## 功能验收

- DSH 0.2.1-rc.2、dsh-TUI 0.17.0、Otty 1.6.2 实机验证通过。
- 确认用户任务结束后正常重启 `dst`，恢复相同会话 ID，原上下文保留；新进程加载最终监听插件。
- 从其他 Otty 标签点击猫条入口，准确选中原工作会话所在标签。
- 重启后的原工作会话通过真实模型调用 `ask_user_question`；猫条展示问题、选项和待处理数，提交后原客户端显示问卷已答并回复“确认回传正常”，提醒撤回。
- 真实客户端服务验收覆盖计划审阅跳转与撤回、普通问题、审批拒绝、请求取消不重新弹出，以及进程退出后的入口回退。具体见 [功能验收记录](../dsh-navigation-acceptance.md)。

## 回归范围

功能阶段已通过 `check-local-agents.sh`、`LocalAgentBridgeChecks.mjs`、`check-agent-data.sh`、`check-agent-interactions.sh` 和 `check-desktop-dock.sh`。覆盖本地数据、真实 Node 与 Swift socket 往返、Cordis 监听、交互和猫条。

发布阶段完整 `check.sh` 和 `check-agent-ui.sh --no-capture` 通过，包括核心逻辑、音频、交互、动效、资源加载、持久化、会话入口和输入焦点。
