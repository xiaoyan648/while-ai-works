# 0.16.0 · 小猫陪你摸会儿鱼

主界面焕新，桌面小猫独立常驻，并与四个小游戏联动。版本 0.16.0，构建号 27。

## 桌面小猫与 AI 状态

- 菜单栏右上角开启「桌面猫」，收起小游戏后仍可陪伴并观察 AI 工作。
- 工作状态默认收起为带会话数的气泡，点击展开具体工具及运行状态；内容较多时用底部渐隐提示滚动。
- 支持拖动并记住位置，在设置中选择小、中、大尺寸，以及墨猫、雪猫两种毛色。
- 支持 Codex、Claude Code、Qoder、WorkBuddy；Claude Code、Qoder、WorkBuddy 通过设置里的「安装监听」接入。

## 小猫陪玩

- 擦污渍：猫爪压着薄荷绿布，新增可以擦净的猫爪印；修复连续小幅擦拭时摩擦声容易断掉的问题。
- 捏气泡：肉垫猫爪按压，气泡连续压缩、破裂、收稳，连续划过按轨迹顺序命中。
- 敲木鱼：猫爪握槌，敲击、声音和计数对齐接触时刻。
- 钓鱼：钓获后，小猫在钓鱼区域上方举起固定卡通小鱼庆祝，展示约 3.8 秒并播放独立收获音效。常驻关闭时也会短暂出现；真实鱼种仍在鱼获卡片中展示。
- 动效支持 macOS「减少动态效果」；声音遵循静音和音量设置。

## 界面与收藏

- 菜单栏面板、设置及鱼获收藏统一样式，鱼获入口归入钓鱼模块。
- 原有鱼种图片、3D 模型、钓竿、奖牌、成就和历史鱼获保留。

## 下载与升级

适用于 macOS 14 或更新版本：

- Apple Silicon（M 系列）：`While-AI-Works-0.16.0-macOS-arm64.zip`
- Intel：`While-AI-Works-0.16.0-macOS-x86_64.zip`

退出旧版后，用解压出的应用替换。原有鱼获、累计记录和设置保留。新接入 Claude Code 时，请安装监听并重新启动客户端；已有 Qoder / WorkBuddy 连接可在设置中检查并重新安装监听。

- 核心玩法、原生交互、音频、AI Hooks、桌面小猫和实际包内资源均经过自动检查。
- Intel 运行检查使用 Rosetta，不能代替 Intel 真机及显卡验收；长时间、多屏和高刷新率使用仍需持续验证。
- 应用采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证；首次启动可能需要在「系统设置 → 隐私与安全性」中选择「仍要打开」。
