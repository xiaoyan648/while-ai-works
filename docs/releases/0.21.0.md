# 0.21.0 · 快捷输入

模型能独立完成的工作越来越多，瓶颈正在转向人。DeepSeek Harness 团队在[《Super-agent 设计探索》](https://mp.weixin.qq.com/s/zoS7GlReWPhfCjENGxXCdg)中写道：「多任务的上限取决于人的注意力」。

猫条已经把进度和卡点收到一处，但发起任务还要逐个切窗口。快捷输入补上这一段：在任何应用里按 `⌥ 空格`，一句话交给 Agent，手上的事不停。

## 新功能

- **随处唤起**：`⌥ 空格`。可以在设置的「快捷输入」里关闭，或换成 `⌃ ⌥ K`、`⌥ ⌘ K`。
- **回车就走**：能直接发送就发送，你留在原地；不能发送就带到对应客户端。`⌘ 回车` 跟过去。
- **`@` 选谁**：Codex、Codex CLI、Claude、Claude Code、Hermes、DSH。DSH 只打开已有会话。
- **`#` 选在哪**：猫条里的会话排在前面，其余按更新时间。浏览显示最近 50 条，更早的输入关键词可以搜到。
- **同家互开**：Codex 和 Codex CLI 看到同一批会话，Claude 和 Claude Code 也一样，选谁就用谁打开。
- **命令行 Agent 跑在默认终端里**：审批和接管都和平时一样，退出或更新猫条不影响它们。

## 改进

- Claude 订阅额度：桌面读取改为每 15～20 分钟一次，失败后逐步拉长间隔。查询失败时保留上次核实过的读数，并显示它实际的获取时间。

## 使用说明

- 桌面端的限制：Codex 桌面端已有的会话可以直接发送；新会话和 Claude 桌面端只能把内容填入输入框或复制，由你按发送。
- Claude Code 命令行没有登录时不能直接发送，选它时会有提示。
- 正在运行或等你处理的会话不会被插话打断，也不会被打开第二次。Codex 通过共享后台服务接入的终端窗口查不出来，会话空闲时可能再开一个窗口接上同一段对话。
- 会话列表只读取这台 Mac 上的记录，不上传。
