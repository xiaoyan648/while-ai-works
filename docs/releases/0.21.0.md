# 0.21.0 · 快捷输入

版本 0.21.0，构建号 45。需要 macOS 14 或更新版本。

## 新功能

- 在任何应用里按 `⌥ 空格`，呼出输入框，把任务交给 Agent，不用切换窗口。可以在设置的「快捷输入」里关闭，或换成 `⌃ ⌥ K`、`⌥ ⌘ K`。
- 回车把内容交出去：能直接发送就发送，你留在原地；不能发送就带到对应客户端。`⌘ 回车` 跟过去。
- `@` 选 Agent：Codex、Codex CLI、Claude、Claude Code、Hermes、DSH。其中 DSH 只打开已有会话。
- `#` 选工作区和会话。猫条里的会话排在前面，其余按更新时间，浏览显示最近 50 条，更早的输入关键词可以搜到。
- 列表按厂商筛选。Codex 和 Codex CLI 看到的是同一批会话，Claude 和 Claude Code 也一样，选谁就用谁打开，比如用 Codex CLI 在终端继续桌面端的会话。
- 命令行 Agent 在系统默认终端里运行，审批和接管都和平时一样。退出或更新猫条不影响它们。

## 改进

- Claude 订阅额度：桌面读取改为每 15～20 分钟一次，失败后逐步拉长间隔。查询失败时保留上次核实过的读数，并显示它实际的获取时间。

## 使用说明

- 桌面端的限制：Codex 桌面端已有的会话可以直接发送；新会话和 Claude 桌面端只能把内容填入输入框或复制，由你按发送。
- Claude Code 命令行没有登录时不能直接发送，选它时会有提示。
- 正在运行或等你处理的会话不会被插话打断，也不会被打开第二次。Codex 通过共享后台服务接入的终端窗口查不出来，会话空闲时可能再开一个窗口接上同一段对话。
- 会话列表只读取这台 Mac 上的记录，不上传。
