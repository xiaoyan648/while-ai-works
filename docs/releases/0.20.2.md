# 0.20.2 · DSH 原会话跳转与确认提醒

版本 0.20.2，构建号 40。需要 macOS 14 或更新版本。

## 修复

- 本地 DSH 会话支持跳回 Otty / iTerm2 的原终端面板。点击前重新校验会话进程；原会话已退出时，复制保留已知 profile 的恢复命令。
- 增强监听安装入口优先识别 `dst` 使用的 `dsh-tui` profile，避免误装到独立的 `tui` 或 `web` profile。
- 计划审阅、限时问题、含详细内容的问题和缺少完整参数的审批也会显示待处理提醒，保留原会话入口。新会话尚未写出日志时仍能收到提醒。
- 普通确认问题与单次工具审批可在猫条处理。回答或取消后清理提醒，已取消问题不再重新弹回原客户端。
- 改善工作卡片的辅助功能操作，展开后可直接访问内容。

## 使用说明

使用 `dst` 的用户需为 `dsh-tui` 安装或更新增强监听，并在当前任务完成后重启客户端。安装说明见 [DSH 接入](https://github.com/xiaoyan648/while-ai-works/blob/main/docs/hermes-dsh.md)。计划审阅等原生专属交互仍在原客户端完成。
