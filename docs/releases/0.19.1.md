# 0.19.1 · 额度读取更稳，卡片切换更顺

版本 0.19.1，构建号 35。需要 macOS 14 或更新版本。

## Codex 额度读取

- 官方额度请求超时由 3 秒调整为 20 秒，避免正常请求尚未返回就被判定超时。
- 仅根据顶层配置和当前选中的配置档判断服务提供方，避免未启用的配置档或其他配置段误关官方额度读取。
- 自定义中转站仍跳过官方账户额度接口；重复点击刷新时复用正在执行的刷新。

## 猫条与工作卡片

- 切换「会话／额度」页签时保留会话列表，减少重复创建和布局。
- 合并卡片高度、桌面小猫和状态栏图标的重复刷新，仅在会话或交互数据发生变化时更新界面。
- 保留 0.19.0 的主 Agent／子 Agent 层级展示、默认折叠和待处理提醒汇总。

## 更新与安装

0.17.1 及更新版本可在「设置 → 关于 → 检查更新」中升级。原有设置和鱼获保留。

- M 系列 Mac：`While-AI-Works-0.19.1-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.19.1-macOS-x86_64.dmg`

退出旧版，打开 DMG，将 **While AI Works.app** 拖入 **Applications（应用程序）**。同时提供两种架构的 ZIP、签名更新清单和 `SHA256SUMS.txt`。

应用采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。更新包和更新清单验证 Ed25519 签名；首次安装可能需要在 macOS「隐私与安全性」中允许打开。Intel 版本为交叉编译，未经 Intel 真机验收。
