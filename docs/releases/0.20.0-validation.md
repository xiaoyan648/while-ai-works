# 0.20.0 发版验证

版本 0.20.0，构建号 37。验证环境：Apple Silicon Mac，macOS；原客户端 Hermes v0.22.5、DSH 0.2.1-rc.2。

## 范围

包含 Hermes / DSH 本地会话、工作状态、Token、增强监听与有限交互支持，官方深浅色图标，以及 Agent 设置页整理。能力边界见 [接入与实测记录](../hermes-dsh.md)，设置页的真实窗口验收见 [设置页验收](../agent-settings-review.md)。

未包含其他工作区的七猫内部托管改动。原 `/Applications/While AI Works.app` 保留。

## 回归检查

以下脚本在发版工作区运行通过：

- `scripts/check-local-agents.sh`：Hermes SQLite、网关标识与空闲状态，DSH 生命周期、用量、重放及原生提问 ID，桥接响应校验。
- `scripts/check-agent-data.sh`：额度新鲜度、Token 维度、回复隐私与原会话回执。
- `scripts/check-agent-interactions.sh`：隔离 Codex owner 通路、过期身份与回执、防重复回答、Claude 请求撤回与草稿、配置保留。
- `scripts/check-desktop-dock.sh --no-capture`：布局、四边贴靠、持久化、窗口边界、独立形态、非激活输入、主题；此项未拍摄真实桌面。
- `scripts/check-agent-ui.sh --no-capture`：文本编辑、会话导航、输入焦点、动画和 Reduce Motion；不作为人工视觉验收。
- `scripts/check.sh`：核心 50 项、动作 114 项、钓鱼 318 项及音频、交互、图形、原生鱼类渲染、鱼图鉴与收藏窗口检查。
- `git diff --check`：通过。

设置专项已通过 `HookChecks` 71 项、原生监听检查、480/520/680pt 深浅色渲染，以及真实 Preview 中的六个配置入口、六个独立关注开关和重启持久化验证。上述交互检查没有向用户真实会话发送回答。

## 安装包与更新

- `scripts/build.sh` 与 `TARGET_ARCH=x86_64 scripts/build.sh` 均通过，两个应用的版本均为 0.20.0 / 37。
- 两种架构的 ZIP 解压后，主程序、状态监听助手和交互助手架构一致；官方 Hermes / DSH 图标与源文件逐字节一致，应用严格签名验证通过。
- 两个 DMG 均完成只读挂载、Applications 快捷方式检查、应用内容逐字节比较及严格签名检查。
- 两份 Appcast 均通过 Ed25519 签名验证；构建号、架构、ZIP URL 与文件大小对应正确。六个文件的 SHA256 与清单一致。
- `scripts/check-updates.sh` 的取消、当前版本、损坏清单、损坏归档、完整安装五种场景均通过；临时应用被正式 ZIP 内容逐字节替换并成功重新启动。
- 更新验收前后核对 `/Applications/While AI Works.app` 的 Info.plist 与主程序 SHA256，原安装未改变。

本机打包与验证日志位于 `.build/release-0200/`；日志及临时应用不随代码发布。GitHub 发布使用草稿上传，待七个资源的远端大小与 SHA256 全部一致后再公开，公开后另检验匿名 Latest 下载入口。

## 验收边界

Hermes / DSH 的真实模型与审批通路已在本机验证，未覆盖所有用户配置、所有 Web/TUI 组合。Hermes 原生提问、DSH 限时问题及计划审阅保留原客户端处理；回复预览和猫条主动发消息尚未接入。

Intel 仅交叉编译与安装包检查，未在 Intel 真机验收。应用使用 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证；Sparkle 更新包及清单有 Ed25519 签名。
