# 0.21.2 验证记录

版本 0.21.2，构建号 47，源码基于 0.21.1 后的 main。已公开发布并设为 GitHub Latest。

## 问题与修复

本机三个 DSH 客户端运行在 Warp，进程持有会话锁并提供 `WARP_FOCUS_URL`。旧解析器只读取 Otty 和 iTerm2 的标识，因此会话仍在终端打开时，WAW 也只能复制恢复命令。

新增 Warp 会话地址校验；精确地址不可用时，通过进程祖先寻找宿主应用，再回退到系统默认的 `.command` 处理应用。通用方式仅唤起应用，需要用户选择标签页。存活会话不重复恢复；过期会话复制恢复命令并打开默认终端，由用户执行。

快捷输入等待异步跳转结果，只在精确入口成功后记录已访问。恢复命令与待发送草稿分别保留，异步跳转不清空期间新写的内容。
