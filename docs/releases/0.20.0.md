# 0.20.0 · Hermes / DSH 加入猫条

版本 0.20.0，构建号 37。需要 macOS 14 或更新版本。

## 新增 Hermes 与 DeepSeek Harness

- 猫条显示 Hermes、DSH 的官方图标、工作状态、会话列表、完成提醒和本机 Token 用量。
- 本地记录独立读取，不等待账户额度接口。使用自备 API Key 时，不显示无法取得的账户余额或剩余额度。
- 按真实委托关系展示子 Agent，复制恢复命令可回到原客户端继续会话。
- 可选增强监听补充准确状态和待处理提醒。DSH 支持普通结构化提问与一次性工具审批；Hermes 显式配置官方 approval transport 后支持一次性工具审批。
- 请求取消、进程退出或超时后失效；无法接管时回到原客户端，不自动批准。

Hermes 的原生提问、DSH 的限时问题与计划审阅仍在原客户端处理。本版尚未接入两者的回复预览和猫条主动发送新消息。已在 Hermes v0.22.5、DSH 0.2.1-rc.2 上完成本机真实模型与审批链路验证，上游接口变化时需重新核对兼容性。

## 设置更清楚

- 分开显示“小游戏启动时机”“关注的 Agent”“授权与提问”。每个 Agent 只出现一次，配置按钮与关注开关统一对齐。
- 修复 Codex、Claude 设置行重复或开关缺失的问题，移除多余空白分隔行。
- 安装、重新安装和移除放入各 Agent 的配置详情，明确区分工作状态监听与授权交互监听。
- 区分未配置、配置不完整、组件缺失、配置已写入和收到监听事件。导出插件不会被显示为已经接通。

首次使用 Hermes / DSH，在“关注的 Agent”中开启对应开关，再进入“配置…”查看增强监听接入说明。安装、重装和移除按原客户端及实际 profile 执行；不会覆盖已有 API Key 或替代原审批机制。

## 更新与安装

0.17.1 及更新版本可通过“设置 → 关于 → 检查更新”升级，原有设置和鱼获保留。

- M 系列 Mac：`While-AI-Works-0.20.0-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.20.0-macOS-x86_64.dmg`

退出旧版，打开 DMG，将 **While AI Works.app** 拖入 **Applications（应用程序）**。同时提供两种架构的 ZIP、签名更新清单和 `SHA256SUMS.txt`。

应用采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证；更新包和更新清单使用 Ed25519 签名验证。Intel 版本为交叉编译，未经 Intel 真机验收。
