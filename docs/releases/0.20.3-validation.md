# 0.20.3 发版验证

版本 0.20.3，构建号 43。新增 Claude 桌面登录复用及手动订阅接入入口。

## 功能验收

- 未授权时，启动与 Claude 关注开关静默检查，没有登录或钥匙串弹窗。
- 用户在设置中手动选择“复用 Claude 桌面登录”并完成 macOS 授权后，实际调用 Anthropic profile 和 usage 成功，账户与组织核对通过。
- 猫条展示真实订阅计划、当前会话及每周剩余额度，与 Claude 桌面端的每周用量一致。未重新登录 Claude，未运行模型调用来获取额度。
- 手动刷新、退出重启后自动刷新均通过；系统日志没有新的授权提示。
- 正式 arm64 包已安装到 `/Applications`，与发行构建逐文件一致，严格签名校验通过。读取助手与用户授权时的 beta.2 完全一致，原授权继续有效；正式包的静默读取和猫条额度显示通过。

## 自动检查

- `check-claude-desktop-usage.sh`：加密缓存、Cookie、账号/组织/主机隔离、撤销、过期、授权失败、API 成功/失败/重定向、查询中切换账户和凭据不输出。
- `check-claude-subscription.sh`：启动和开关不登录、不申请授权；手动复用、桌面优先、CLI 回退、无需 CLI 也能获取桌面额度、共享缓存、provider 输出，以及原有登录的取消和超时清理。
- `check-agent-data.sh` 通过；`check-ui.sh --claude-subscription` 生成的完整设置与用量视图完成明暗布局检查。
- `check-updates.sh` 完成真实 Sparkle 取消、已是最新版、篡改清单、损坏归档和正常升级检查。升级后的隔离应用与正式 arm64 包逐文件一致，并成功重新启动。
