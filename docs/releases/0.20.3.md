# 0.20.3 · 复用 Claude 已有登录

版本 0.20.3，构建号 43。需要 macOS 14 或更新版本。

## 改进

- 查询订阅额度时优先复用 Claude 桌面端当前账户的登录，再尝试 Claude Code 的订阅登录，无需保持命令行客户端运行。
- 启动猫条、开启关注或调整 Claude 监听只做静默检查，不自动弹出登录或钥匙串授权。
- 设置和猫条用量页提供手动“复用 Claude 桌面登录”入口。只有用户点击后才申请系统读取授权；没有可复用登录时，可手动登录订阅账户。
- 区分尚未授权、登录过期、网络查询失败等情况，不再把读取失败统一显示为“已退出登录”。
- 核对当前账号和组织，避免切换账户后显示旧账户额度；凭据仅用于向 Anthropic 查询，不复制到猫条设置。

## 使用说明

Claude 已登录但猫条尚无读取权限时，在设置的 Claude 接入配置或猫条用量页点击“复用 Claude 桌面登录”，由用户完成 macOS 钥匙串授权。允许后可后台刷新；如果原登录过期，按提示打开 Claude 更新登录状态。

桌面读取兼容当前 Claude 客户端的本地格式，格式变化时会停止读取并尝试 Claude Code。API Key 或中转站认证不等于订阅账户登录；本机会话 Token 统计仍可独立显示。
