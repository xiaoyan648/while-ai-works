# 0.19.0 · 子 Agent 收进猫条

版本 0.19.0，构建号 34。需要 macOS 14 或更新版本。

## 主 Agent 与子 Agent

- 主 Agent 的子 Agent 默认收起，点击「子 Agent」入口后按层级缩进展示；更深的子树可以继续单独展开。
- 子 Agent 的待回答与待审批会汇总到折叠入口，并将整个会话组排到「待你处理」，不会自动展开或夺走输入焦点。
- 会话数量上限只计算主 Agent，保留被选中主会话的完整子树，避免子 Agent 挤掉父会话或静默消失。

## 中转站与额度读取

- Codex 使用自定义中转站时，不再请求只对官方服务有意义的账户额度接口；本机会话和 Token 用量仍继续统计。
- 官方额度读取设置 3 秒短超时；中转站、网络不可用或 app-server 无响应时，猫条仍可切换会话与页签。

## 更新与安装

0.17.1 及更新版本可在「设置 → 关于 → 检查更新」中升级。原有设置和鱼获保留。

- M 系列 Mac：`While-AI-Works-0.19.0-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.19.0-macOS-x86_64.dmg`

退出旧版，打开 DMG，将 **While AI Works.app** 拖入 **Applications（应用程序）**。同时提供两种架构的 ZIP、签名更新清单和 `SHA256SUMS.txt`。

应用采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。更新包和更新清单验证 Ed25519 签名；首次安装可能需要在 macOS「隐私与安全性」中允许打开。Intel 版本为交叉编译，未经 Intel 真机验收。
