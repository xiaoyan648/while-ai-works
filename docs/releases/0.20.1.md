# 0.20.1 · 修复 DSH 桌面环境读取

版本 0.20.1，构建号 38。需要 macOS 14 或更新版本。

## DSH

- 修复使用 fnm 安装 Node.js 时，DSH Web / TUI 已启动，猫条仍提示“读取 Harness 数据需要 Node.js”的问题。桌面启动不会继承终端的版本管理器环境，本版补充 fnm、nvm、Volta 安装目录识别，并优先使用 fnm 的默认版本。
- 保留已有 PATH 的优先级，不执行 shell 启动脚本，不修改 DSH 配置或 API Key。
- 本地读取失败时显示“读取异常”，避免“等待连接”被误解为需要重启 DSH。

## 安装与更新

通过“设置 → 关于 → 检查更新”升级，或者下载对应芯片的 DMG。原有设置和鱼获保留。

- M 系列 Mac：`While-AI-Works-0.20.1-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.20.1-macOS-x86_64.dmg`

应用使用 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证；更新归档与清单有 Ed25519 签名。Intel 为交叉编译及安装包校验，未做 Intel 真机验收。
