# 0.17.3 · 轻量安装，鱼缸按需下载

版本 0.17.3，构建号 31。需要 macOS 14 或更新版本。

## 更轻的应用

- 鱼缸模型和纹理改为独立资源包，默认安装不再携带。Apple Silicon 应用约 54 MiB，ZIP 约 30 MiB，较此前分别减少约 80% 和 86%。
- 首次进入「收藏 → 水下观赏」时提示下载约 187 MiB，点击「下载并开启鱼缸」后才开始联网。支持进度、取消和失败重试，下载期间可继续使用小猫、钓鱼和鱼图鉴。
- 下载完成后校验并安装到本机缓存，之后可离线观赏；普通应用更新复用同版本资源。鱼缸模型和纹理质量不变，已有鱼获、收藏和入住名单保留。
- 从旧版升级后，首次开启鱼缸也需要下载一次独立资源包。

## 猫条体验

- 增大 Agent 详情卡片，让较长的问题和选项更容易阅读。
- 运行中的 Agent 图标加入轻微左右摆动和更清晰的呼吸缩放。额度环保持稳定，空闲、隐藏或开启「减少动态效果」时停止动画。

## 更新与安装

0.17.1 及更新版本可在「设置 → 关于 → 检查更新」中升级。0.17.0 及更早版本需手动安装一次。原有设置和鱼获保留。

- M 系列 Mac：`While-AI-Works-0.17.3-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.17.3-macOS-x86_64.dmg`

退出旧版，打开 DMG，将 **While AI Works.app** 拖入 **Applications（应用程序）**。同时提供两种架构的 ZIP、签名更新清单和 `SHA256SUMS.txt`。

应用采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。更新包和更新清单验证 Ed25519 签名；首次安装可能需要在 macOS「隐私与安全性」中允许打开。
