# 0.21.1 发版验证

版本 0.21.1，构建号 46。快捷输入新增「回来的入口」。

## 功能验收

- 维护者在预览包（独立偏好，无游戏和声音）上试用列表、按键和拼音输入后决定发版，没有逐项记录结果。
- 预览里「刚完成」出现过 21 小时前的会话：预览是全新偏好，没有去过的记录，比正式升级后更杂。时间窗口保持 24 小时，和猫条爪印一致。

## 未经自动验证

这台 Mac 的 shell 没有屏幕录制和辅助功能权限，以下项目只有模拟检查：

- 真实输入法组词。检查用 `setMarkedText` 模拟组词、取消和选词。
- 从列表和猫条真实回到各客户端的会话窗口。检查覆盖路线选择：用会话自己的客户端、每次重新读取进程、开着的会话不恢复、等你处理且到不了时打开猫条卡片。
- 爪印在运行中图标上的显示。规则在状态层验证。

## 自动检查

- `check.sh`、`check-quick-input.sh`、`check-agent-data.sh`、`check-agent-interactions.sh`、`check-ui.sh`、`check-desktop-dock.sh`、`check-local-agents.sh`、`check-hooks.sh` 通过。`check-desktop-dock.sh` 此前在未改动的 main 上有焦点和摆动两项失败，这次通过。
- `check-quick-input.sh` 新增：列表内容与容量、去过与移出、路线、键盘、组词，以及深浅两种外观的列表和组词绘制图。
- `check-updates.sh`：真实 Sparkle 流程的取消、已是最新、篡改清单、损坏安装包、正常升级全部通过，发行归档逐字节安装并重新启动，未替换 `/Applications` 中的应用。

- arm64 与 x86_64 构建通过，主程序与三个助手架构一致，严格签名校验通过；两个 DMG 校验通过。包内更新源、公钥、Sparkle 与 Rive 框架齐全。
