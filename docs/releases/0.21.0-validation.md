# 0.21.0 发版验证

版本 0.21.0，构建号 45。新增快捷输入。

## 功能验收

- 同家互开逐个方向实测：`codex resume` 打开桌面端会话，历史完整显示；`codex://threads/ID` 打开命令行会话，桌面端接管其日志；`claude://resume?session=ID` 导入后生成 `local_ID.json`；`claude --resume ID` 能认出桌面端会话并询问是否恢复，这台 Mac 的命令行未登录，没走到发送。
- 真实端到端：Codex CLI 新会话与 Hermes 新会话发送并回复，在上一轮提交上通过；本轮只跑续发。测试会话已有窗口接入时再接入续发，一条消息只收到一次、回复一次，焦点未变。
- 本机真实记录：读取约 20 毫秒，可达会话 107 条（猫条 38 条），每个 ID 一条，各 Agent 的列表没有混入别家。

## 未经自动验证

这台 Mac 的 shell 没有屏幕录制和辅助功能权限，以下项目只有模拟按键的检查，没有真机结果记录。维护者决定直接发版：

- `⌥ 空格` 唤起和输入、真实拼音输入（包括 `#` 搜索）、玻璃材质和动画手感。
- Codex 桌面端已有会话的发送和 `⌘ 回车` 填入。
- Claude 桌面端新会话的填入。

## 自动检查

- `check-quick-input.sh`：符号解析、链接、启动脚本、按厂商筛选、浏览上限与搜索、同家互开、占用判断、DSH、本地记录解析、真实面板里的键盘事件。
- `check.sh`、`check-agent-data.sh`、`check-desktop-dock.sh`、`check-agent-interactions.sh`、`check-ui.sh` 通过。
- `check-updates.sh`：真实 Sparkle 流程通过，发行归档逐字节安装并重新启动。
- `check-release-resources.sh` 没跑完：它要求本机先打水族箱资源包，停在这一步。这次资源没有改动，它也不在发版步骤里。
