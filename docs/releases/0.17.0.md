# 0.17.0 · 小猫收成一条，Agent 一眼看清

版本 0.17.0，构建号 28。桌面小猫新增猫条模式，把 AI 工作状态、会话事件和账户额度放进屏幕边缘的小工作台。

界面示例，账户与会话均为演示数据。

## 猫条与工作卡片

- 在设置中切换「猫条 / 宠物」。猫条保留猫耳与尾巴，拖到屏幕四边可贴边停靠，横竖方向随边缘切换。
- 悬停 Agent 预览工作卡片，点击固定；小猫趴在卡片边缘。支持浅色、墨黑与跟随系统外观。
- 图标页签切换会话与额度，运行中的标志轻微呼吸，额度环保持静止；支持系统「减少动态效果」。
- 简短回复直接展示，长回复在文字省略号上悬停查看全文，无需额外阅读窗口。

## Codex / Claude Code

- Codex 与 Claude Code 通过本机原客户端读取订阅额度；CLI 需要对应官方订阅登录。Claude Desktop 登录不自动等于 Claude Code 已登录。
- 会话按待回答、待审批、完成与运行状态整理。可用的 Codex 问题卡直接接入；工具授权与 Claude 问题需在设置中显式安装交互监听并重启会话。
- 提问、授权只在对应会话处理，未主动选择不会自动批准。断线、过期或发送结果待确认时保留状态；不确定时请到原会话查看。
- 回复预览默认关闭，可在设置中开启，正文只保留在本机内存。Qoder / WorkBuddy 继续支持原有工作状态监听；本次账户额度与回复接入面向 Codex / Claude Code。

## 用量更清楚

- Claude 猫条优先显示当前会话额度，Codex 显示每周额度；卡片可滚动查看其他限制和重置时间。
- 输入、输出、缓存读取对齐展示，悬停可看精确数字；新增 Token 构成条、缓存命中率和总计。
- 用量摘要固定在卡片底部，不受额度列表的滚动与渐隐影响。数字按本机最近会话累计，不代表今日用量或订阅账单。

## 下载与升级

需要 macOS 14 或更新版本：

- M 系列 Mac：`While-AI-Works-0.17.0-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.17.0-macOS-x86_64.dmg`

打开 DMG，将 **While AI Works.app** 拖到 **Applications（应用程序）**。升级前先退出旧版，再替换应用；原有设置与鱼获保留。也提供 ZIP 与 `SHA256SUMS.txt`。

应用采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。首次打开可能需要按 macOS「隐私与安全性」提示操作。Intel 包在 Apple Silicon 上交叉构建，Rosetta 检查不等于 Intel 真机及显卡验收。
