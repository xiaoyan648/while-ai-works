# 0.18.1 · 回答可粘贴，小猫换图标

版本 0.18.1，构建号 33。需要 macOS 14 或更新版本。

## 输入回答更顺手

- 修复猫条问题卡片和独立处理浮窗中无法使用 ⌘V 粘贴的问题，支持中文、多行内容和 Emoji。
- 补齐剪切、复制、全选、撤销和重做快捷键；即使菜单栏仍属于其他应用，已进入的回答输入框也能正常编辑。
- 收起后保留回答草稿；新的请求不会切走正在填写的回答，只读预览不接管粘贴。

## 灵猫新图标

- 应用图标换成与桌面小猫呼应的墨色灵猫：尖耳、薄荷色发光眼睛和弯尾。
- 重新制作各尺寸应用图标，保留 macOS 圆角、透明外边距和轻柔阴影。

## 更新与安装

0.17.1 及更新版本可在「设置 → 关于 → 检查更新」中升级。原有设置和鱼获保留。

- M 系列 Mac：`While-AI-Works-0.18.1-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.18.1-macOS-x86_64.dmg`

退出旧版，打开 DMG，将 **While AI Works.app** 拖入 **Applications（应用程序）**。同时提供两种架构的 ZIP、签名更新清单和 `SHA256SUMS.txt`。

应用采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。更新包和更新清单验证 Ed25519 签名；首次安装可能需要在 macOS「隐私与安全性」中允许打开。Intel 版本为交叉编译，未经 Intel 真机验收。
