# 0.17.2 · 会话跳转入口修复

版本 0.17.2，构建号 30。需要 macOS 14 或更新版本。

## 会话入口

- 修复猫条中「运行中」和「最近会话」的跳转按钮被隐藏的问题。有可用入口的 Codex / Claude 会话均可回到原会话。
- Claude 终端会话只有恢复命令时，改用复制图标；点击后显示已复制提示，在原终端执行即可继续。
- 没有跳转地址或恢复命令的记录不显示入口。提问与授权仍优先显示对应处理按钮。

## 更新与安装

0.17.1 用户可在「设置 → 关于 → 检查更新」中升级。0.17.0 及更早版本需要手动安装一次。原有设置和鱼获保留。

- M 系列 Mac：`While-AI-Works-0.17.2-macOS-arm64.dmg`
- Intel Mac：`While-AI-Works-0.17.2-macOS-x86_64.dmg`

退出旧版，打开 DMG，将 **While AI Works.app** 拖入 **Applications（应用程序）**。同时提供 Sparkle 使用的两种架构 ZIP、签名更新清单和 `SHA256SUMS.txt`。

应用仍采用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证。更新包和更新清单验证 Ed25519 签名；首次安装可能需要在 macOS「隐私与安全性」中允许打开。
