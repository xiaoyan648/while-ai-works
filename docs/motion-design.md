# 猫条与全局配色、动效设计方案

2026-10-16 设计并实施。交互预览：`design/motion-preview/index.html`（浏览器直接打开）。

## 已确定的方向

| 主题 | 决定 |
| --- | --- |
| 配色基调 | 以猫条为准：纸白／墨黑表面 + 唯一的薄荷强调色，主面板和设置窗跟随 |
| 动效性格 | 轻弹：弹簧回弹 0.15–0.25，统一成一套时长 token |
| 运行动效 | ±8° 连续正弦摆动 + 呼吸缩放，各 Agent 错相 |
| 完成标记 | 右上角圆角标 + 猫爪印，和「?」同形同尺寸；盖章动画 |
| 标记保留 | 看过才消失；新一轮运行自动清除 |
| 请求与完成并存 | 请求在前，爪印在后露出一角；悬停沿额度环展开 |
| 运行 → 完成 | 先停稳再盖章 |
| 伴随反馈 | 猫条猫头耳朵抖一下 + 新合成的软「啪嗒」音效 |
| 卡片出现 | 从触发图标长出来，小猫随后爬上卡片 |
| 切换 Agent | 选中底色滑动 + 卡片内容交叠 |
| 主面板 | Hero 小猫跟随完成事件、数字滚动、玩法卡片选中、开始玩联动 |
| Rive | 新增 `notice`（耳朵抖 + 眨眼）和 `stretch`（伸懒腰）两个触发器 |

## 1. 配色 token

全部定义在 `Theme`，猫条、详情卡、主面板、设置窗共用。不再在视图里写十六进制颜色。

| Token | 浅色 | 深色 | 用途 | 替换 |
| --- | --- | --- | --- | --- |
| `surface` | `#FAFAFC` | `#060708` | 猫条、详情卡、主面板、设置窗底色 | 主面板 `.popover` 材质；`DesktopDock` 中的字面量 |
| `well` | 黑 4.5% | 白 6% | 分组行、玩法卡片 | 不变 |
| `wellStrong` | 黑 7.5% | 白 10% | 悬停、选中底色、额度环轨道 | 不变 |
| `accent` | `#237E60` | `#8EDCC1` | 唯一的绿：强调文字、选中、额度环、Codex 标志着色、运行状态点 | 旧 `accent` `#2F7A63/#6CC6A5`、`working` `#2F9A6C/#5FD39A`、Codex tint 字面量 |
| `accentBadge` | `#8EDCC1` | `#8EDCC1` | 完成角标底色 | 新增 |
| `accentBadgeInk` | `#0F3B2C` | `#0F3B2C` | 角标上的爪印 | 新增 |
| `attention` / `attentionBadge` | 不变 | 不变 | 请求角标、待处理文字 | 不变 |
| `badgeInk` | `#211B0D` | `#211B0D` | 「?」「!」数字 | `DesktopDock` 字面量 |
| `inkSecondary` | `#505660` | `#CDD2DA` | 三点菜单等独立绘制的次级图形 | `DesktopDock` 字面量 |
| `gold` / `silver` | 不变 | 不变 | 奖牌 | 不变 |

对比度：`accent` 在 `surface` 上浅色 4.8:1、深色 12.6:1；爪印 `#0F3B2C` 在 `#8EDCC1` 上 7.8:1。

- **主面板与设置窗**：默认实色 `surface`，和猫条、详情卡成为同一个家族；「设置 → 外观 → 面板材质」可改为毛玻璃，主面板、设置窗与桌面小猫状态卡随之透出系统材质。猫条与详情卡始终为实色。玩法卡片、开关行继续使用 `well`。
- **Hero 森林**：保留 `ForestBackdrop`，深色光晕 `#6FDCC6` 改为 `accent` 深色值 `#8EDCC1`；浅色底渐变 `#EFF5F2 → #DCE8E4` 不变，作为全应用唯一带色调的面。
- **运行状态点**（`ActivityDot`、桌面宠物状态卡）改用 `accent`，不再有第二种绿。

## 2. 动效 token（轻弹）

新增 `Motion`，SwiftUI 与 Core Animation 使用同一组数值。Core Animation 弹簧用 macOS 14 的 `CASpringAnimation(perceptualDuration:bounce:)`。

| Token | 曲线 | 用途 |
| --- | --- | --- |
| `fast` | 0.15s easeOut | 悬停底色、淡入淡出、角标淡出 |
| `snap` | spring 0.25s，bounce 0.15 | 按压、选中滑动、角标展开、内容切换 |
| `base` | spring 0.38s，bounce 0.22 | 卡片展开、印章落定、摆动停稳 |
| `slow` | 0.6s easeInOut | 额度环数值变化、配色与昼夜 |
| `loop` | 2.4s 正弦 | 运行摆动 |

现有 `Theme.spring` 等于 `base`，`Theme.quick` 改为 `snap`。

**减少动态效果**：所有弹簧换成 `fast` 淡入淡出；循环、位移、缩放、耳朵抖动、印泥涟漪全部取消；状态仍通过静态角标、文字和辅助功能标签表达。音效不属于动态效果，照常播放。

## 3. 猫条

### 3.1 运行摆动

现状的问题：五个关键帧 `0 → 12° → 0 → −12° → 0` 每段 easeInEaseOut，经过 0° 时也减速，一轮停四次，看起来一顿一顿；呼吸绑定在同一组关键帧上，所有 Agent 同相同步摆。

| 项 | 规格 |
| --- | --- |
| 旋转 | `CABasicAnimation` −8° ↔ +8°，单程 1.2s，`autoreverses`，easeInEaseOut。只在两端减速，经过正中时最快 |
| 呼吸 | 1.00 ↔ 1.06，单程 0.6s，`autoreverses`；一轮摆动呼吸两次，经过正中时最大 |
| 错相 | 按 `WorkSource.dockOrder` 序号 × 0.6s 设置 `timeOffset`；固定值，界面刷新时不跳变 |
| 起步 | 从 0° 用 0.6s easeOut 摆向 +8° 后接入循环，不从中间突然开始 |
| 停止 | 读取 presentation layer 当前角度和缩放，移除循环，用 `base` 弹簧回到 0° 和 1.0 |
| 不变 | 额度环静止；标志中心与点击区域固定；不可见或遮挡时暂停；不经过 `AppState` |

### 3.2 完成印章

**触发**：某个客户端出现新的 `.finished` 会话事件，且事件时间晚于该客户端的「已看时间」。只认客户端明确报告的完成，停顿或无活动不算，与现有规则一致。

**已看时间**：按客户端在偏好中保存一个时间戳，不含会话内容。卡片展示过该客户端（悬停打开或点击固定）之后，在离开它时更新：切换到其他客户端，或卡片收起。悬停期间爪印保持可见，这样才能看到 3.3 的展开。重启后旧完成不会再次盖章；24 小时完成窗口外的事件不显示。

**角标**：15pt 圆形，`accentBadge` 底，1.5pt `surface` 描边，中心 `pawprint.fill` 8pt `accentBadgeInk`。位置、尺寸、描边与「?」角标完全一致（图标中心偏移 16, −16）。

**时序**（运行中 → 完成）：

| 时间 | 动作 |
| --- | --- |
| 0 | 摆动按 3.1 停止方式用 `base` 弹簧回正（约 0.35s） |
| 0.35s | 印章从 1.9 倍、−16°、透明开始落下 |
| 0.52s | 接触帧：缩放 0.84；标志被压到 0.92 后回弹（0.28s）；从角标扩散一圈 1.2pt 薄荷印泥环，1 → 2.1 倍、透明度 .55 → 0（0.5s）；播放音效；猫条猫头耳朵抖动 |
| 0.67s | 回弹到 1.07 |
| 0.77s | 落定 1.0 |

**同时完成**：1.5 秒内多个客户端完成，印章依次错开 0.08s；音效和耳朵抖动只发生一次。

**消失**：离开已展示过的该客户端卡片 → 角标 `fast` 缩到 0.6 并淡出；新一轮运行开始 → 同样移除并开始摆动。

**辅助功能**：图标标签追加「，有新完成」；悬停提示追加「已完成 · 14:32」。

### 3.3 请求与完成并存

- 需要用户处理的请求（「?」「!」或数量）占前位：沿额度环外圈（半径 22.6pt）45° 位置，也就是现在的位置。
- 爪印在请求后面，沿同一圆周错开 9°，露出一个小月牙。
- 悬停图标：爪印用 `snap` 弹簧沿圆周滑到 26° 外，完全露出并留 1.5pt 间隙；请求角标反向让 4°。移开后收回。
- 展开方向朝屏幕内侧：竖向贴右沿、横向贴下沿时向上（逆时针）；竖向贴左沿、横向贴上沿时向右（顺时针）。
- 请求处理完：请求角标 `fast` 淡出，爪印 `snap` 滑回 45° 前位。
- 只有爪印时直接在前位。

### 3.4 猫头耳朵

`CatDockContour` 里两只耳朵现在合并进轮廓路径。改为：轮廓路径继续负责填充与鼠标穿透，耳朵另外绘制成两个独立图层，填充色相同，锚点在耳根。

抖动：0 → −8°（0.12s easeOut）→ +4° → 0（`snap` 弹簧），两耳相差 0.04s。只在盖章接触帧触发。

### 3.5 详情卡展开与收起

| 项 | 规格 |
| --- | --- |
| 锚点 | 触发图标中心（现有 `anchor`） |
| 展开 | 内容图层缩放 0.92 → 1，从猫条方向偏移 8pt → 0，透明 0 → 1，`base` 弹簧；只动图层，不改窗口 frame |
| 小猫 | 延迟 0.1s，Rive 视图从卡片上沿下方 6pt 升起并淡入，像爬上卡片 |
| 收起 | 0.18s easeIn，缩到 0.96 并淡出，结束后 `orderOut` |
| 不变 | 首次悬停 100ms 停留、离开后 450ms 保留、点击固定 |

### 3.6 切换 Agent

- 猫条选中圆底用 `matchedGeometryEffect` 在图标间 `snap` 滑动，不再分别淡入淡出。
- 卡片窗口和 Rive 画布原地复用，不重播展开动画。
- 标题区和会话列表 0.2s 交叠：新内容沿移动方向轻滑 6pt 淡入，旧内容原地淡出。竖向猫条往下切换，新内容从下方进入。

### 3.7 其他细节

- 图标按压缩放到 0.94，`snap`。
- 额度环读数变化时裁剪量用 `slow` 过渡；运行状态不影响额度环。
- 请求角标出现沿用印章落下曲线，但不带涟漪、音效和耳朵，幅度减半（1.4 倍起）。

## 4. 主面板

- **底色**：按第 1 节改为实色 `surface`。
- **Hero 小猫**：任一已关注客户端出现新完成，且面板可见时，触发 Rive `notice`，同时应用把 `lookX` 偏向猫条所在一侧 0.6，保持 0.4s 后交还鼠标跟随。与猫条共用 1.5 秒合并窗口。
- **状态胶囊**：文字变化从淡入淡出改为上下推入（`.push(from: .bottom)`，`snap`）。
- **数字**：玩法卡片计数、木鱼值、总鱼获、本次计数全部使用 `numericText`，并绑定 `snap` 动画。现在卡片计数有 `contentTransition` 但没有绑定动画值，需要补上。
- **玩法卡片选中**：已有 `matchedGeometryEffect`，动画从 `base` 改为 `snap`；图标 `bounce` 保留；颜色换成新的 `accent`。
- **开始玩开关**：打开时触发 Rive `stretch`，约 0.8s 后进入对应玩法 mood；标题和说明交叠切换。关闭时直接回到 `idle` / `sleep`，复用现有 mood 过渡。

## 5. Rive 新增

在 `design/mascot/build_scene.py` 中添加，属性名固定：

| 属性 | 类型 | 动作 |
| --- | --- | --- |
| `notice` | 触发器 | 双耳后压 8° → 过冲 4° → 回正（0.3s），0.2s 时眨眼（闭眼 80ms）；`seated` 与 `perched` 都可用 |
| `stretch` | 触发器 | 仅 `seated`：身体压低拉长、闭眼、耳朵后压，再略微弹起落定，约 0.8s；现有骨骼没有可单独伸出的前爪，不做前爪动作 |

看向猫条由应用通过 `lookX` 完成，不写进 Rive，避免和鼠标跟随冲突。

## 6. 音效

在 `Audio.swift` 用代码合成 `stampWAV()`，与现有木鱼、咬钩音效同样方式，不增加包体积：

- 约 90ms：140 → 90Hz 正弦低音，2ms 起音、25ms 衰减；叠加 0–12ms 经低通的短噪声，模拟印章的「嗒」。
- 比木鱼低约 6dB；跟随应用音量与静音；1.5 秒内最多播放一次。

## 7. 性能约束

- 循环与一次性动画都在 Core Animation 图层上，不写入 `AppState`，不重建会话列表。
- 窗口不可见或被遮挡时暂停循环（沿用现有遮挡监听）。
- 卡片展开只动内容图层 transform 与透明度，不在动画中改窗口 frame。
- 印章和耳朵抖动是一次性动画，结束后移除。

## 9. 验收要点

- 摆动录屏逐帧检查：经过 0° 时角速度最大，没有停顿；四个客户端不同相。
- 运行 → 完成：先回正，再盖章；接触帧与音效、耳朵同步。
- 请求与完成并存时，「?」始终可点、可读；悬停展开不越出屏幕边缘。
- 悬停期间爪印可见并展开，离开该客户端卡片后消失；重启应用不再出现已看过的爪印。
- 减少动态效果：无循环、位移和缩放，角标直接淡入，状态仍可读。
- 浅色、深色各一组对比度检查；主面板改为实色底后，与猫条、详情卡并排截图对照。

## 实施说明

- 卡片收起有 0.18s 退场动画。控制器的 `cardVisible` 在退场开始时即为 false，命中检测与外部点击判断以它为准；窗口在动画结束后才真正隐藏，期间不接收鼠标，重新打开会接管它。
- Qoder / WorkBuddy 若不上报明确的完成事件，就不会出现爪印，已写入 `docs/cat-dock.md`。
