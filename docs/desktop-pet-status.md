# 桌面小猫的 AI 工作状态

启动时默认收起，不恢复旧版本保存的展开状态。小猫保持原来的位置与摸猫、拖动操作。

- 运行时显示奶白思考气泡、薄荷绿状态点与进行中会话总数；超过 99 时显示 99+，辅助功能和展开标题仍提供准确数量。
- 点击气泡，在小猫上方展开材质卡片。再次点击气泡、卡片收起按钮或点到小猫区域外，都可收起。面板不获取键盘焦点。
- 卡片按工具列出运行会话及最近观察到的阶段：处理请求、思考、调用工具、整理回复。没有任务标题或正文时不编造描述。会话编号用于当前列表，工具内增减会话时可能重新编号。
- 会话全部离开运行状态后，短暂显示勾号并淡出。这个反馈表示当前没有运行中的会话，不保证任务成功；原有五分钟静默超时仍适用。切换关注工具、关闭小猫和读取异常不触发此反馈。
- 空闲时气泡隐藏，仍可右键小猫选择“展开 AI 工作详情”查看连接情况。
- 尊重系统“减少动态效果”；停止弹性数字变化与渐隐。静止时气泡不循环闪烁。

Codex 仅解析事件类型与生命周期。Qoder / WorkBuddy 的本地 Hook 快照新增可选的固定枚举 phase，兼容旧快照，不保存提示词、回复正文、工具参数。已安装的旧 helper 在更新到本构建前仍能提供数量，缺少 phase 时显示“正在处理请求”。

## 验证

- `scripts/check-desktop-pet.sh --no-capture`：默认收起及旧偏好、会话汇总、外部点击、固定小猫坐标、按钮与卡片命中分流、显示与位置恢复。
- `scripts/check-hooks.sh`：旧快照兼容、阶段枚举、三工具 3→2→1→0、重复事件与过期恢复、关闭后清空详情。
- `scripts/check.sh`：核心、音频、小游戏交互与动效、鱼获及原生界面回归。
- 独立实窗样例：`output/pet-status/小猫状态验收.app`，使用临时配置和模拟运行会话；收起/展开截图也在该目录。截图中的 3 个会话是验收数据。

真实非激活悬浮窗已通过辅助功能按钮验证展开/收起。当前电脑控制工具对该类窗口的坐标点击返回 noWindowsAvailable；鼠标命中区域由原生 NSView 测试补充，尚未完成真实鼠标拖动的人工验收。
