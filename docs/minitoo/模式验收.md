# MiniToo 手动双模式 · 本地开发验收

## 范围

- 设置中手动选择「鱼缸 / Codex」，保留独立总开关；不自动切换，不做完成提醒跳转。
- 鱼缸同步水下观赏入住列表与真实鱼种素材；最多六条，成员改变才重新上传。
- Codex 展示本机近期会话状态、运行时长、账户额度快照和更新时间；多页手动翻页。
- 内置游戏、自定义游戏、摇杆、Wi-Fi/USB 图像传输均未纳入本次实现。

## 本地检查

以下检查均已通过；最终 arm64 应用签名验证通过。

- `scripts/check-minitoo.sh`：协议向量、完整帧解码、分包重组、关闭取消、模式保存、页码边界、鱼素材对应；Codex 恢复任务、旧轮完成、中断、无事件超时、额度窗口/空值/新旧快照。
- `scripts/check-hooks.sh`：原有 41 项 hooks 检查及原生多客户端监听回归，新增桌面/跟随/来源选择关闭时的 MiniToo 独立状态采集。
- `scripts/check.sh`：原有玩法、原生交互、鱼素材和设置渲染回归。
- `scripts/build.sh`：本地 arm64 构建；最终包已通过 `codesign --verify --deep --strict`。
- 检查日志：`.build/minitoo-modes-{check,hooks,regression,build}.log`。
- `aquarium.png/gif` 使用三种示例鱼，`codex-example.png` 使用测试会话和测试额度；是画面渲染验证，不是设备照片。

## 真机状态 · 2026-09-21

- 已启动新版并通过设置操作「鱼缸 / Codex」，桌面游戏保持关闭。
- 真正的六种入住鱼（鲫鱼、沙丁鱼、河鲈、虹鳟、三文鱼、鲶鱼）上传获最终 ACK；用户确认有画面，同时指出移动太快。
- Codex 当前真实会话和周额度上传获最终 ACK；用户确认“Codex 页面正常，文字清楚”。不是仅用测试数据模拟。
- 按反馈将鱼缸改为 48 帧、200 ms/帧，循环 9.6 秒；缩小游动范围，掉头逐渐侧转。新动画上传获 ACK，速度主观验收待用户反馈。
- 包间隔从 20 ms 改为 5 ms；连续亮屏更新不再重复等待 0.5 秒；相同预览复用，上传进度最多每秒发布十次。
- 日志文件事件触发采集，100 ms 合并；保留 1.5 秒兜底轮询。文件监听最多 48 个，目录最多 24 个，退出监听时关闭描述符；发现历史任务仍按最近修改时间。
- 当前轮完成、中断、迟到事件隔离、超时恢复由本地测试验证。真实任务本轮还在运行，没有冒充完成状态的真机验收。

快速切换最终按最后选择显示；关闭后重新开启收到 Codex ACK。测试结束恢复慢速鱼缸，开关保持开启供观察。
