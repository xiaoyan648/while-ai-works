# MiniToo 工作 Agent

入口：设置 → MiniToo → 工作模式 → 打开 Agent 工作台。MiniToo 模式始终由用户手动选择；打开工作台、模型回答或 Codex 任务完成都不会自动跳转模式。文字任务可以在设备关闭时执行。

## 配置与分发

1. 展开「火山引擎配置」，选择接口类型。
2. 普通推理默认模型为 `doubao-seed-2-0-lite-260215`；可改为自己账户有权限且支持工具调用的模型 ID 或接入点 ID。
3. 填入自己的 API Key，保存后测试连接。留空保存不会覆盖已有密钥；「移除密钥」只删除本应用的钥匙串项。
4. 发给其他用户的应用不带密钥；每个人都必须在自己的 Mac 上配置。

普通推理使用 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`。Coding Plan 使用 `https://ark.cn-beijing.volces.com/api/coding/v3/chat/completions`，默认 `ark-code-latest`，需要相应套餐及模型权限。两种接口不能混用额度，模型权限以使用者账号为准。普通推理已实测，Coding Plan 尚未实测。

密钥保存于 macOS Keychain，service 为 `local.whileaiworks.mac.ark-agent`，不会写入 UserDefaults、源代码、对话或安装包，也不通过 iCloud 同步。偏好设置只保存接口类型、模型 ID 和 Mac 操作开关。请求不接受 HTTP 重定向，不展示可能回显凭证的原始错误响应。任务文字和工具结果会发送给所选火山服务。

对话仅保存在当前应用内存，工作台最多展示 80 行消息，模型保留最多 8 个完整轮次并按约 48 KB 裁剪。新对话、修改模型配置或移除密钥都会清空历史；退出应用不会保存聊天文件。当前为非流式文本回答。

## 可执行工具

| 工具 | 作用与边界 |
| --- | --- |
| `get_app_status` | 当前桌面开关、玩法、入住鱼和 MiniToo 展示状态 |
| `get_codex_status` | 本地日志中的近期任务编号、状态及额度快照；不读取提示词和回复，不是云端实时额度 |
| `set_desktop_game` | 用户明确要求时开启或收起桌面游戏 |
| `set_minitoo_display` | 用户明确要求时切换鱼缸 / Codex / 工作模式，或关闭展示；返回发送状态，不把请求提交当成设备确认 |
| `open_app` | 开启「允许打开应用和网页」后，可打开 Safari、备忘录、计算器、日历、访达 |
| `open_webpage` | 同一开关下交给默认浏览器打开 HTTPS URL，不读取网页；拒绝凭证 URL、文件地址、脚本协议、常见本地地址及自定义端口 |

没有任意 Shell、文件读写、自动点击屏幕、发送消息或删除文件工具。URL 校验不是浏览器网络隔离，也不保证网页不会重定向；该工具只负责打开用户要求的页面。

工具参数在本地逐项校验，不支持的名称和参数不会执行。每轮最多 6 次模型请求、12 个工具调用，重复调用编号不重复执行。点击停止会取消请求，并阻止后续工具启动；已经打开的应用或已经改变的开关不会自动撤销。执行过程显示在工作台中。

## 动画与语音

文字任务使用同一个 Agent 入口：输入 → 火山模型 → 本地工具 → 工具结果回传 → 最终回答。工作模式中，任务开始上传思考动画，完成上传完成动画，取消或失败回到待机。图片只在状态变化时上传，设备自行循环播放；蓝牙通道串行发送，并合并尚未开始的中间状态。

工作台已加入点击开始/结束收音、豆包录音极速识别和流式语音回复；识别结果进入同一 Agent 工具循环。API Key、音色和音频设备在「语音与音频设备」中单独配置。语音权限取决于所配 Key；历次云端测试和真机验收边界分别记录。[语音配置与验证边界](voice.md)

豆包端到端实时闲聊在独立「闲聊模式」中接入，开启后持续收音，结束后停止；支持手动打断及可选语音打断。工作模式仍采用录音、识别与播报分开的流程。没有唤醒词或摄像头采集。

## 验证方式

- `bash scripts/check-agent.sh`：固定响应测试覆盖工具循环、上下文、参数拒绝、取消、重复调用、上限、HTTP 错误和凭证脱敏，不访问云端或设备。
- `bash scripts/check-minitoo.sh`：动画、编码、传输容器、展示状态与 Codex 解析回归。
- `bash scripts/build.sh`：构建本地应用；`bash scripts/check.sh` 运行原有玩法与设置回归。
- 真正的云端和 Mac 操作验收使用正式工作台完成，结果见下方记录；固定响应测试不能代替此项。
