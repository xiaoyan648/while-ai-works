猫条动效预览

配合 docs/motion-design.md 阅读。客户端标志是占位图形，会话为演示数据。悬停右侧猫条图标打开卡片；点击可固定。

「完成」：先停稳，再盖章。同时完成时依次错开 0.08s，只响一次、耳朵只抖一次。请求和爪印并存时，悬停图标可以看到爪印沿环展开；离开这个 Agent 的卡片后，爪印记为已看并淡出。

运行摆动：现在与新方案

现在的版本每段都 easeInEaseOut，经过正中也会停一下；新方案只在两端减速。

现在
0 → 12° → 0 → −12° → 0，每段停顿，1.8s
新方案
−8° ↔ +8° 连续正弦 2.4s，经过正中时呼吸最大
